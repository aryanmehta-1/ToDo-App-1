# 📌 Overview

The **To-Do App** is a lightweight productivity application that allows users to organize tasks in a simple and interactive way.

The application is divided into two sections:

### 📋 Left Panel

Displays all the tasks dynamically.

### ➕ Right Panel

Allows users to add new tasks instantly.

Users can:

* Add tasks
* Mark tasks as completed
* Delete tasks
* Interact with the UI in real-time without page refresh

# ⚙️ How the Application Works

## 1️⃣ User Enters a Task

The user types a task into the input field.

## 2️⃣ Task Gets Added

When the form is submitted:

* JavaScript captures the input
* Creates a new task element dynamically
* Displays it inside the task list

## 3️⃣ Mark as Complete

Clicking the ✔ button toggles the completed state.

Completed tasks:

* Get strike-through text
* Turn gray visually

## 4️⃣ Delete Task

Clicking the ✖ button removes the task instantly.
